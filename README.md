# Ghost of Space

Космический шутер на Pygame. Защищайте корабль и базу, собирайте бонусы,
выбирайте улучшения между волнами и сражайтесь с боссами каждые 5 уровней.
Оригинальные изображения, музыка и таблица рекордов сохранены.

**[Скачать игру для Windows (.exe)](https://github.com/GIFONOT/Ghost_of_Space/releases/latest/download/GhostOfSpace.exe)**

Скачайте файл и запустите его — Python устанавливать не нужно. Для публичного
репозитория вход в GitHub не требуется. Ссылка заработает после публикации
первого релиза с EXE; пока релиз не выпущен, файл по ней недоступен.

## Запуск

```sh
python3 -m pip install -r requirements.txt
python3 Game.py
```

Можно также запускать `main.py`. Пути к ресурсам не зависят от текущей папки.
Если аудиоустройство недоступно, игра запускается без звука.

## Сборка для Windows и macOS

Используется PyInstaller: Python, Pygame, изображения и звук входят в сборку.
Получателю не нужно устанавливать Python. Собирать нужно на целевой системе:
Windows создаёт один `GhostOfSpace.exe`, macOS — приложение `GhostOfSpace.app`,
которое Finder показывает как один объект. Для macOS используется режим
`onedir`: все зависимости находятся внутри `.app`.

Windows, PowerShell из папки проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build.py
```

Результат: `dist\GhostOfSpace.exe`. Передавайте именно этот файл.

Если Windows под рукой нет, в репозитории подготовлен GitHub Actions workflow
`.github/workflows/build-windows.yml`. После загрузки актуального кода в GitHub
откройте **Actions → Build Windows EXE → Run workflow**. Дождитесь успешного
завершения и скачайте **Artifacts → GhostOfSpace-Windows-x64**. В ZIP будет
один `GhostOfSpace.exe` Артефакт хранится
30 дней; обычная сборка запускается вручную, а публикация релиза — по тегу версии.

### Публичная ссылка для скачивания

После загрузки актуального кода и workflow в репозиторий создайте новый тег
версии (пример для первого релиза):

```sh
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions соберёт EXE на Windows и опубликует его в **Releases**.
Кнопка скачивания в начале README всегда ведёт на EXE последнего релиза.
Для следующих обновлений используйте новый тег, например `v1.0.1`.
Публичный репозиторий позволяет скачивать релизы без аккаунта; приватный
репозиторий по-прежнему требует доступа. Для поля Website в разделе About
можно использовать `https://github.com/GIFONOT/Ghost_of_Space/releases/latest`.

macOS, Terminal из папки проекта:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python build.py
open dist/GhostOfSpace.app
```

Для передачи приложения с сохранением структуры и символических ссылок:

```sh
ditto -c -k --sequesterRsrc --keepParent dist/GhostOfSpace.app dist/GhostOfSpace-macOS.zip
```

Приложение собирается под архитектуру используемого Python. Для Intel Mac и
Apple Silicon нужны соответствующие сборки; этот скрипт не создаёт universal2.
Публичное распространение на macOS без предупреждения Gatekeeper требует
подписи Developer ID и notarization; текущая локальная сборка их не выполняет.
Windows также может показывать предупреждение SmartScreen для неподписанного EXE.

В сборках настройки и рекорды сохраняются между обновлениями:

- Windows: `%LOCALAPPDATA%\GhostOfSpace\`.
- macOS: `~/Library/Application Support/GhostOfSpace/`.

Личные `Settings.json` и `Scored.json` разработчика в сборку не включаются.
При запуске из исходников они по-прежнему читаются из папки проекта.
`build.py` обновляет результаты в `build/` и `dist/`.

Документация: [PyInstaller: сборка на целевой ОС](https://pyinstaller.org/en/stable/usage.html),
[пути ресурсов внутри приложения](https://pyinstaller.org/en/stable/runtime-information.html).

## Управление

- WASD / стрелки — движение; Space — стрельба.
- Движение с лёгкой инерцией: плавный разгон и короткое скольжение после
  отпускания клавиш (около 33 пикселей на базовой скорости). Рывок срабатывает сразу.
- Shift — рывок с краткой неуязвимостью, перезарядка 3 секунды.
- Esc / P — пауза; потеря фокуса окна также ставит игру на паузу.
- Меню: мышь или стрелки и Enter. Esc — назад.
- Между уровнями: выбор улучшения мышью, Enter или цифрами 1–4.
- После поражения: R — новый забег, либо кнопка возврата в меню.

По умолчанию включён русский язык. Английский можно выбрать в настройках;
выбор сохраняется. Шрифт поддерживает кириллицу, включая имена пилотов.
Также доступны музыка, эффекты, автострельба и восемь обликов корабля.
Настройки записываются в `Settings.json`, результаты — в `Scored.json`.

## Сложность

Перед стартом и в настройках можно выбрать лёгкую, обычную или сложную игру.
По умолчанию выбрана обычная. Выбор сохраняется и применяется к новому забегу;
текущий режим указан на игровом экране.

| Режим | Здоровье врагов | Урон по кораблю и базе | Скорость врагов | Частота выстрелов | Скорость пуль | Число врагов |
| --- | --- | --- | --- | --- | --- | --- |
| Лёгкая | 65% | 50% | 80% | 61% | 75% | 75% |
| Обычная | 82% | 75% | 90% | 80% | 90% | 90% |
| Сложная | 100% | 100% | 100% | 100% | 100% | 100% |

Сложная соответствует прежнему балансу. Множители действуют и на боссов.
Размеры волн округляются до целого числа врагов.

## Баланс

В обычной волне 9–24 врага, появляющихся небольшими группами. Одновременно
на экране не более 4–14 противников. В техническом прогоне обычные волны
занимали 11–21 секунду; реальная длительность зависит от тактики игрока.
После последнего врага оставшиеся бонусы автоматически собираются за
0,75 секунды — ждать их падения больше не нужно.

Шесть типов врагов открываются постепенно:

- Бирюзовый жук-рейдер движется поперёк экрана и ведёт прицельный огонь.
- Янтарный крылатый пришелец заходит сбоку, маневрирует и стреляет парой пуль.
- Золотистый панцирный краб ненадолго удерживает позицию и стреляет веером.
- Голубой кальмар-охотник стреляет с упреждением по движению игрока.
- Изумрудный таранщик «Богомол» обозначает направление и выполняет быстрый рывок.
- Фиолетовый снайпер «Оракул» задерживается в верхней части поля и выпускает быстрые пули.

Враги защищены во время входа в игровую область: уничтожить их за экраном
нельзя. Направление прицельной атаки фиксируется перед выстрелом, давая время
уклониться. Пропущенный враг повреждает базу; столкновения не приносят очков.
После попадания корабль защищён 0,65 секунды.

Боевые дропы теперь только ремонтируют корабль или базу. Постоянные усиления
выбираются между уровнями. Дополнительные стволы расширяют залп, распределяя
урон между пулями, а не умножая его в несколько раз. Пределы: урон 24,
интервал стрельбы 0,14 секунды, вампиризм 6%, три ствола.
После волны восстанавливается 5 здоровья корабля и 3 здоровья базы.
Ремонт вместо улучшения восстанавливает 30 корпуса и 25 базы.

## Боссы

В главном меню доступен **Boss Run**: Страж, Буря и Владыка подряд, без обычных
волн. Выберите сложность и готовый билд — таран, пробой или гибрид.
Между боями кнопка «Следующий босс» полностью ремонтирует корабль и базу,
восстанавливает рывок. После третьего босса забег завершается победой.
Рестарт повторяет Boss Run с тем же билдом; результаты не попадают в рекорды.

Каждый пятый уровень — отдельный бой. Три босса чередуются на уровнях
5, 10, 15, затем повторяются с увеличенным здоровьем. Сложность продолжает
влиять на здоровье, урон, частоту атак и скорость вражеских пуль.

| Босс | Первая фаза | Вторая фаза |
| --- | --- | --- |
| Страж | Три последовательных рельсотрона, включая позицию игрока; широкий прицельный веер; перекрёстный расстрел | Быстрый таран; перекрёстный расстрел; ударные волны с веером пуль |
| Буря | Вращающиеся спирали; минное поле; мины на позиции игрока с ударной волной | Гравитационная ловушка с четырьмя спиралями; перекрёстные лазеры; прицельные мины с волной |
| Владыка | Высадка эскорта; самонаводящиеся ракеты; осадный луч с ракетами | Лазерный коридор и эскорт, защищающий ядро; ракетная охота; осадный луч с ракетами |

Между основными атаками боссы выпускают прицельные тройные залпы с небольшим
упреждением. Во второй фазе они стреляют и перемещаются быстрее. Интервал
основных приёмов — 1,9/1,45 секунды (у Владыки на 0,4 секунды больше),
дополнительно применяется множитель сложности. Сильные атаки фиксируют
цель до срабатывания: после разметки нужно менять позицию.

До множителя сложности пули босса наносят 30 урона, ракеты — 36, лучи — 48,
ударная волна — 38, мины — 34, центр гравитационной ловушки — 24.
Контакт с боссом наносит 60 урона до таранной брони. Здоровье босса:
2600 на уровне 5, 3700 на уровне 10 и 4800 на уровне 15, затем применяется
множитель сложности. Обычные враги и их урон не изменены.

При половине здоровья начинается вторая фаза: старые опасности исчезают,
босс перестраивается 1,4 секунды и меняет набор атак. Сильный удар не может
перескочить этот переход. Мины можно уничтожать пулями; через ударную волну
можно пройти рывком. Рывок также позволяет вырваться из гравитационного поля.
Оранжевая разметка обозначает подготовку атаки; яркие лучи уже наносят урон.
Ракеты доворачивают к игроку только первые 1,25 секунды.

Пули наносят 70% урона по броне босса; таран и пробивающие снаряды игнорируют
эту броню. После таранного выпада Страж ненадолго открывает ядро и получает
135% урона. Щит Владыки во второй фазе снимается уничтожением эскорта —
бронебойные пули не обходят этот щит. Эскорт не даёт очков и ремонтных дропов.
Победа удаляет оставшиеся опасности и даёт дополнительный ремонт.

## Билды

После волны предлагается до четырёх вариантов: развитие тарана, развитие
пробоя, обычное усиление и ремонт. Одно выбранное улучшение расходует весь
выбор этого уровня. Ветки можно смешивать; ранг следующего улучшения показан
на карточке, текущие ранги — в HUD и на паузе.

### Таран

- **Таранный корпус, 3 ранга:** контакт наносит урон раз в 0,65 секунды по
  каждой цели; каждый ранг даёт +20 максимального здоровья с общим пределом 250.
- **Форсаж, 2 ранга, требует таран:** сокращает перезарядку рывка с 3 до
  2,35 и затем 1,7 секунды.
- **Живая крепость, 2 ранга, требует таран:** максимальное здоровье усиливает
  контактный урон; убийство тараном восстанавливает 3/6 здоровья. Увеличивает броню.

Во время рывка таран наносит в 2,2 раза больше урона. Броня уменьшает
контактный урон, но не защищает от лазеров, мин и пуль. Таран не уничтожает
босса автоматически и не повторяет попадание каждый кадр. Вампиризм работает
с фактически нанесённым уроном, в том числе от тарана.

### Пробой

- **Пробивающие пули, 3 ранга:** каждый ранг добавляет одну сквозную цель
  (итого до четырёх) и +2 урона с общим пределом 24.
- **Рельсовый ускоритель, 2 ранга, требует пробой:** каждый ранг умножает урон
  на 1,4, задержку между залпами на 1,18 и повышает скорость снаряда.
- **Сквозной разгон, 2 ранга, требует пробой:** после попадания пуля сохраняет
  82% урона без улучшения, 96% на первом ранге и 110% на втором.

Одна пуля попадает в конкретную цель только один раз. Пересечения проверяются
на всём пройденном отрезке, поэтому быстрый снаряд не пропускает корабли между
кадрами. Мины тоже можно пробивать; несколько стволов расширяют область залпа.

## Визуальные эффекты

При попадании отдельно разлетаются частицы цвета пули и фрагменты обшивки
поражённого врага. Взрыв использует средний цвет, палитру и настоящие участки
его спрайта; прозрачные пиксели исключены из расчёта цвета. Палитры кэшируются.
Добавлены вспышки попаданий, затухание обломков, движущиеся звёзды, пламя
двигателя и предупреждения о выстрелах и таранах.

Технические прогоны проверяют работоспособность прогрессии. Точная сложность
и удобство уклонений требуют ручного плейтеста.

## Новые спрайты

Два новых корабля доступны в выборе облика: синий «Кречет» и оранжевый «Бастион».
Новые враги «Богомол» и «Оракул» используют поведение таранщика и снайпера;
они появляются с 6-го и 8-го уровня соответственно. Изображения хранятся в
`Png/ship-kestrel.png`, `Png/ship-bastion.png`, `Png/enemy-mantis.png` и
`Png/enemy-oracle.png`. При загрузке они приводятся к общей пиксельной сетке.

Новые модели боссов: `Png/boss-warden.png`, `Png/boss-tempest.png`,
`Png/boss-overlord.png`. Запросы ImageGen: `Png/BOSS_ART_PROMPTS.md`.

Все шесть обычных врагов оформлены как живые пришельцы в едином пиксельном
стиле: панцири, клешни, глаза и щупальца вместо кабин и двигателей. Боссы
сохраняют свои боевые платформы, но теперь ими управляют видимые монстры.
Фон `Png/background-nebula.png` добавляет туманности и далёкую планету;
центр остаётся тёмным для читаемости снарядов. Новые запросы для обычных
врагов и фона сохранены в `Png/ALIEN_ART_PROMPTS.md`.
